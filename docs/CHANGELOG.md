# 变更说明

## Qi2.2 加密设置协议

- 在原生面板中增加加密写入路径，步骤与参考实现一致：重新握手 → 查询当前状态（已是目标值则直接返回）→ 读取健康度/循环次数 → 派生会话密钥 → 加密写入 → 回读校验。
- 回读只比对「状态码成功 + Qi2.2 开关位与目标一致」；健康度/循环次数仅参与生成密文，不做数值比对。
- 旧型号继续使用原有明文指令；两条路径共用原卡片 UI、忙碌锁与错误提示。
- 加密实现与参考实现逐字节比对：20 组用例（短序列号补零、时间戳边界、开关两态）全部一致。
