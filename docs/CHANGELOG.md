# 变更说明

## Qi2.2 加密设置协议

- 在原生面板中增加加密写入路径：重新握手 → 读取健康度/循环次数 → 派生会话密钥 → 加密写入 → 回读校验。
- 旧型号继续使用原有明文指令；两条路径共用原卡片 UI、忙碌锁与错误提示。
- 加密实现与参考实现逐字节比对：20 组用例（短序列号补零、时间戳边界、开关两态）全部一致。

## 型号放开与标注

- WPB1026S、WPB0525S：开放开关，标注「加密协议」。
- WPB1025：走加密协议，标注「可能支持 · 未经测试」，按钮为「未经测试尝试开启」。
- 型号总数 18，旧版独有型号（P25 / AC1067 / P15 / PB2020）保留可查看。

## 开启成功率统计

- 新增 `qi2_reports` 表，按（型号, 序列号摘要, 动作）去重。
- 界面按样本量分级展示：<5 显示「统计中」；错误率 >30% 黄色提示；<10% 绿色带勾选。
- 回传失败不影响开关结果。

## 遥测与反调试

- 移除 IP / UA / 指纹 / 访问日志采集，删除历史采集表与备份对象。
- 移除自毁、内存炸弹、控制台检测、调试器计时等反调试脚本。
- 保留 CSP、nonce、环境门槛、PoW、完整性签名、地区判定与真实点击校验。

## 品牌与迁移

- 移除页面小米图标（favicon），避免商标误用。
- 旧域名页面顶部提示迁移到新域名；新域名不再显示该提示。
- 顶部说明栏增加本仓库开源地址。
